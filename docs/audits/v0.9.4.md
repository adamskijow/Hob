# v0.9.4 coordinated-completion audit

## Incident

`I did home insurance and hit the grift` completed the first named task and
treated the second as a future start.

## Fix at release

A narrow reconciliation converted that model proposal into two completions only
for explicit coordinated past-tense wording. Future and partial-progress clauses
kept their original meaning.

## Evidence

- Exact production wording through interpreter and MessageService
- Future `will do` and partial `worked on` contrasts
- Real 14B case

## Current status

v0.9.8 removed raw-text semantic repair. Typed model scope and tense decisions
now cover this behavior; the core validates IDs and effects.
