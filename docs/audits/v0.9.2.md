# v0.9.2 displayed-list scope audit

## Incident

An evening reply such as `finished all except the taxes` could affect unrelated
open tasks that never appeared in the recap.

## Fix

- Persist the exact actionable IDs and order after successful recap delivery.
- Expire that context after 24 hours.
- Remove tasks that have since closed.
- Ask for a list when no valid presented context exists.
- Give the model the same displayed IDs and order.

## Evidence

- Planner regression with three displayed and two unrelated tasks
- MessageService storage check
- EOD context integration check
- 74/74 real-model cases
