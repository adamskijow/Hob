# v0.9.11 desktop recovery audit

## Trigger

A restart left the owner without a visible way to start Hob.

## Shipped

- Native Open Local menu-bar companion
- Running, off, needs-setup, and unavailable states
- Turn On, Restart, Check Health, logs, and data-folder actions
- Repeatable `scripts/install_macos.sh` update and repair
- Configuration preservation and ambiguous-database refusal
- `scripts/hobctl` fallback for Terminal and remote sessions
- Stable launchd restart without overlapping Telegram pollers
- Privacy-safe health using aggregate status only

The menu controls the fixed `com.local.hob` service. Telegram tokens remain in
Keychain. The App Store shell stays separate and sandboxed.

## Evidence

Shell syntax, plist lint, service tests, installer tests, Swift tests, Python
suite, EventKit, Xcode, real-model corpus, live install, restart, and health
checks passed.
