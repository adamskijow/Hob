# v0.9.8 model-owned language audit

## Result

All free-text turns reach the local model. Typed output owns settings, date
meaning, planning constraints, bulk scope, exclusions, recurrence, retraction,
and contextual answers. Code owns IDs, provenance, bounds, arithmetic,
confirmation, atomicity, and undo.

Focused model passes handle recap, stale-task, confirmation, setup, planning,
and disagreement checks. Closed protocols such as slash commands, callbacks,
reactions, IDs, and ordinals remain deterministic.

Raw date/deadline parsers, phrase repairs, and `dateparser` were removed.

## Evidence

- 417 Python tests
- Real-model corpus expanded from 84 to 102 cases
- Settings undo restored absent metadata correctly
- Full Python, 14B model, lock, syntax, Swift, EventKit, Xcode, and CI gates
- Live accidental `eod_time` change restored from its recorded before-state

## Open risks at release

Extra semantic passes add latency. Every supported model still needs complete
corpus evidence. The Store runtime needs the same typed contracts.
