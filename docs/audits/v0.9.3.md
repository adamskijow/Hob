# v0.9.3 Telegram service-event audit

## Incident

Pinning the morning digest generated a Telegram status update. Hob treated it as
unsupported owner media and sent a confusing fallback at 07:00.

## Fix

Telegram status updates advance the durable offset without entering the content
handler, typing state, model, or outbox. Owner media keeps its text fallback;
captioned media keeps the normal message path.

## Evidence

- Lightweight and real `telegram.Update` pin cases
- Membership status case
- Captioned and uncaptioned owner-media cases
- 367 Python tests, 29 Swift tests, and 74/74 real-model cases
- Xcode shell/helper/model tool, EventKit, syntax, and lock checks

Telegram may add new service types; aggregate library classification remains a
regression target.
