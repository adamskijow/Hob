# v0.9.7 zero-completion recap audit

## Incident

`Nothing got done` during an evening recap was treated as an unknown task
message.

## Fix at release

A deterministic phrase matcher recognized several zero-result answers when a
recent recap list existed. It acknowledged the report and left every task open.

## Evidence

Production wording, context expiry, mixed positive/negative reports, no-op undo,
and proactive copy received regressions.

## Current status

The phrase matcher proved too narrow for open language. v0.9.8 replaced it with
typed model interpretation and a code-owned no-mutation guarantee.
