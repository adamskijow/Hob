# Hob 1.0 acceptance

Status: local native preview.

Baseline: 484 Python tests, 55 native tests, signed iPhone and Mac development
builds, and green Ubuntu/macOS CI. The latest public tag, `v0.9.13`, belongs to
the retired Open Local edition.

## Gates

| Area | Proven | Required |
| --- | --- | --- |
| Capture | Local typed Foundation Models actions, validation, undo | Preserve shorthand fixed times end to end; expand noisy and regional cases |
| Planning | Work profile, Calendar busy time, proposal, adoption, replan | Sustained use, stale-result recovery, DST and timezone matrix |
| Calendar | Opaque reads, transactional adoption and cleanup | Denial, revocation, all-day, overlap, timeout, and restart rehearsal |
| Reminders | Morning digest; start reminders; Done, Snooze, Replan; durable cleanup | Sleep, restart, DST, and denied-permission rehearsal |
| Sync | Bounded private per-device journal and offline merge tests | Signed two-device offline-edit rehearsal |
| Recovery | Durable state, validation, backup migration tests | Corruption, disk-full, interrupted write, and rollback drill |
| Accessibility | Labels and responsive SwiftUI layouts | VoiceOver, large text, contrast, keyboard, and date comprehension |
| Onboarding | Model, iCloud, Calendar, reminders, work profile | Fresh install through first adopted schedule without developer help |
| Operations | Native Mac menu bar and local signed installs | Reboot, login, update, rollback, and seven days without manual repair |
| Distribution | Local development signing | Versioning, privacy metadata, screenshots, archive validation, TestFlight, review |

- Native and legacy suites plus exact-commit CI pass.
- iPhone and Mac run the same version and commit.
- Local data survives restart, offline edits, and rollback.
