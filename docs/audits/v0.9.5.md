# v0.9.5 plain digest-decision audit

## Incident

The stale-task digest asked for `keep`, `tomorrow`, or `drop`, but plain mobile
messages lost their prompt context unless sent as Telegram replies.

## Fix

- Store the prompted item ID and send time.
- Accept one same-day decision for that exact prompt.
- Let newer task focus block destructive stale choices.
- Consume the context after use.
- Support waiting-item resume through the same prompt identity.

## Evidence

Keep, move, drop, resume, expiry, single-use, newer-focus, old-pin, and empty-
nudge regressions passed.

## Current status

v0.9.8 moved free-text decision meaning to the model. Prompt identity, age,
single-use state, and allowed effects remain code-owned.
