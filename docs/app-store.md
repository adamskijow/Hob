# Apple app

Status: signed development builds run locally on the paired iPhone and Mac.
Nothing has been uploaded.

## Complete

- Shared Swift core and SwiftUI workspace
- On-device Foundation Models interpretation
- Typed task persistence and undo
- Deterministic schedule proposals
- EventKit availability and explicit Calendar adoption
- Durable reminders, cancellation, and reviewed replans
- Private bounded iCloud journal sync
- First-run setup and connection menu
- Signed local iPhone and Mac builds

## Before 1.0

1. Preserve shorthand fixed times through the full capture and planning path.
2. Rehearse offline edits and convergence on both devices.
3. Reboot the Mac and verify menu-bar startup.
4. Finish VoiceOver, large text, contrast, and keyboard checks.
5. Validate notification actions across restart.
6. Prepare privacy metadata, screenshots, signing, and archive validation.

Store distribution remains paused until the user asks for it.
